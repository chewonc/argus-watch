Statuses are evidence-based: live observed on production, local exercised end to end against real APIs and Meta models, needs setup implemented but waiting on credentials, not built.

Two things only you can unblock

  • Muse Code works locally; the Actions run needs your secrets. Muse Code 1.4.14 ran headless and sandboxed through the full runner script and made the correct fix (docs/VALIDATION_MUSE_CODE.md). Fix & create PR / Fix & push stay hidden until you set the variables in SETUP §1b.
  • A real pull request has never been created. It needs FIX_ENABLED=1 plus a repository with the App's write permission and changes enabled.

C. Remaining gaps

  • Muse Code runner verified locally only; not yet run on GitHub Actions (Linux sandbox) or triggered by production.
  • No real pull request or merge has been created by Argus.
  • NVD's first production run returned HTTP 503; local calls succeed.
  • Agentic investigation compared on 3 fixtures only; the 16-case harness was not rerun with it.
  • Some deep technical panels and the fix dialog remain English; first Korean view of a case takes about 40 s until translations are cached.
  • Web Push needs VAPID keys; email, X, LinkedIn, Threads not available.
  • Simulation, agentic investigation and the Korean case page were verified locally, not on production with a signed-in session.

Remaining security risks

  • Muse Code now runs with its sandbox on and no shell or web tools, which closes the API-key exfiltration path. The repository's own tests, when present, still run in the VM without secrets.
  • Push mode merges automatically once checks pass; branch protection is respected but not required.

E. Walkthrough for a new user

  1. Open the site, pick a language with the 🌐 selector, click Sign in with GitHub.
  2. Account menu → Repositories → Connect GitHub, install the App on chosen repositories.
  3. Tick repositories → Start monitoring. Argus checks the last 30 days of matching threats right away.
  4. Alerts arrive in Alerts and the bell, ordered by what needs you most, each with a report-credibility label.
  5. Open an alert: what's wrong, exact file and lines, Open file in GitHub, Is this threat real?, and Simulate user impact.
  6. Click Fix, review the diff, then Fix & create PR or Fix & push (once the runner is configured).
  7. Settings → Connect AI agent: Meta Muse Code, Claude Code or Codex over MCP with a personal token.
